## 已知限制

- NCU 内部必须创建 Linux POSIX FIFO；NTFS 挂载目录不支持该操作。因此 profiler 内部临时 IPC 使用 Linux `/tmp`，其他用户文件仍落在 `/mnt/`。
- Conda history 导出不锁定 pip 包，需同时保留 `requirements.lock.txt`；它是安装版本快照，不是带哈希的完整锁文件。
- NTFS 挂载盘的 JIT 编译和文件 I/O 条件与原生 Linux 文件系统不同，正式性能实验需注明。
- NCU 使用 `--clock-control none`，不改变现有 GPU 时钟；本次只证明指标采集与报告读取可用，不把短 kernel 的耗时当作正式 benchmark。
- 临时 MSI CAB/payload 缓存自动清理被工具策略拦截，未提供更具体原因，当前保留于 `.cache/windows-msi/`。
